# Yankee Park - Lot Mapping

An interactive SVG-based map visualization of Yankee Park's parking and camping lot layout.

## Overview

This project displays a detailed interactive map of Yankee Park featuring:
- **85 numbered parking/camping lots** organized in multiple sections
- **Key buildings**: Pole Barn, Clubhouse, and Volleyball Court
- **Roads and lot boundaries** for easy navigation
- **Responsive design** that adapts to different screen sizes

## Features

- Interactive SVG map with hover effects
- Clean, modern UI with a professional layout
- Lot numbers clearly labeled on the map
- Organized lot groupings for easy reference

## Usage

Open `yankee-park-map.html` in any web browser to view the interactive lot mapping.

## Files

- `yankee-park-map.html` - Main map interface with embedded styles and SVG graphics

## Tech Stack

- HTML5
- SVG (Scalable Vector Graphics)
- CSS3 for styling and responsive layout
